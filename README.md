## Lorenz Cipher
A terminal-based cryptography tool that leverages the **Lorenz Attractor** and the **4th-order Runge-Kutta (RK4)** numerical method to generate a highly sensitive, pseudo-random keystream (PRNG) for file encryption.
By relying on deterministic chaos, even a microscopic variation in the initial conditions generates complete divergence in the bitstream, ensuring robust XOR-based encryption.

## Features 
*   **Interactive TUI:** Terminal user interface for seamless execution without graphical dependencies.
*   **Recursive Processing:** Encrypts or decrypts single files or entire directory trees.
*   **Secure Wipe:** Original plaintext files are overwritten with random bytes before deletion to prevent forensic recovery.
*   **Numba JIT Optimization:** Mathematical loops are compiled to machine code (C) in real-time, significantly accelerating the integration process for large files.

## Mathematical Foundation
The keystream is generated by numerically integrating the Lorenz system of ordinary differential equations:

$$ \frac{dx}{dt} = \sigma(y - x) $$
$$ \frac{dy}{dt} = x(\rho - z) - y $$
$$ \frac{dz}{dt} = xy - \beta z $$

Where the standard parameters $\sigma = 10$, $\rho = 28$, and $\beta = 8/3$ are utilized. A derivation function maps a PBKDF2-HMAC (SHA-256) hashed 16-byte master key into the highly sensitive initial conditions $(x_0, y_0, z_0)$.

## Installation
**1. Clone the repository:**
```bash
git clone https://github.com/l01-jcc/Lorenz-Cipher
cd Lorenz-Cipher
```
**2. Set up a virtual environment (Required for Arch Linux):**
```bash
python3 -m venv venv
source venv/bin/activate
```
**3. Install dependencies:**
```bash
pip install -r requirements.txt
```
**4.Make the script executable:**
```bash
chmod +x Lorenz-Cipher.py
```

## Usage
Run the tool directly from the terminal:
```bash
./Lorenz-Cipher.py
```
**Warning** Ensure the hexadecimal master key provided during encryption is securely stored. If the key is lost, the encrypted data is mathematically unrecoverable.
